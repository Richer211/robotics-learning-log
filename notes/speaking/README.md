# English Speaking Practice

口语练习闭环：**写稿 → 录音 → 复盘 → 改进 → 写回日志**。

## When to Start

| 阶段 | 要求 |
|------|------|
| Week 1 | 只写 English Summary + Key Terms，**不录音** |
| Week 2 起 | 每天写 60-second Speaking Draft；可先读稿 |
| Month 2 起 | 每周 1–2 次录音 + 复盘 |

## Workflow

### 1. Write

在当天 [`notes/dayXX.md`](../day01.md) 填写 **60-second Speaking Draft**。

### 2. Record

- 用手机或 Mac QuickTime 录约 60 秒
- 保存到：`notes/speaking/dayXX.mp3`（或 `dayXX/` 文件夹）

### 3. Review

在 Cursor 里使用 **english-speaking-review** 技能，提供录音或转写，获取：

- 表达评分
- 修改版英文
- 值得保留的表达
- 下次练习建议

### 4. Update Log

把「修改版输出」和「值得保留的表达」抄回当天日志。

## Folder Layout

```
notes/speaking/
├── README.md          ← 本文件
├── day08.mp3          ← 录音（可选，不提交大文件时可 gitignore）
└── day08-review.md    ← 复盘摘要（建议提交）
```

## Tips

- 不追求高级词汇；先讲清楚「做了什么、为什么、学到什么」
- 第一周允许看稿读；熟练后再脱稿
- 和技术学习绑定：讲完当天 demo，不要讲空泛话题

## 60-second Template

```
Today I worked on ___.

The goal was to ___.

I wrote a program that ___.

The main thing I learned was ___.

One problem I had was ___.

Tomorrow I plan to ___.
```
