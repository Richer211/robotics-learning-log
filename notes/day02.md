## How I Solved Them

-  多练习，grep 是搜查文件内容，ls -la是展示当前目录下的所有文件包括隐藏文件，echo '' >  .txt 是把某个内容全覆盖进某个文件，echo "" >> .txt 是把某个内容加入到某个文件末尾， git diff --staged必须是已经加入缓存区的文件的变动可以查出来 而git diff -> 看还没git add的改动， git log --oneline 是看出当前所有提交的日志记录，mv 是把某个文件移动或重命名为新文件， touch 是创建一个新的空文件
